# Human Intent Prediction for Adaptive Lower-Limb Exoskeletons

This repository contains the research project on predictive human intent recognition for adaptive lower-limb exoskeletons.

## Overview

The project focuses on developing and evaluating deep learning approaches for recognizing locomotor intent and enabling adaptive assistance in lower-limb exoskeleton control.

It includes:
- the full monograph in Markdown
- the compiled PDF version of the documentation
- code for data generation, preprocessing, training, and experiments
- sections with literature review, methodology, discussion, and conclusions

## Main objective

To design an intent-aware control strategy that anticipates human locomotor decisions and improves the responsiveness and safety of lower-limb exoskeleton systems.
